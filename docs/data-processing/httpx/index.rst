HTTPX2
======

`HTTPX2 <https://pydantic.dev/docs/httpx2/get-started/>`_ is an HTTP client that
can be used seamlessly as a replacement for `HTTPX
<https://httpx.readthedocs.io/en/latest/>`_ and simplifies HTML requests
compared to the Python standard library’s :doc:`urllib.request
<python:library/urllib.request>`.

Installation
------------

You can easily install HTTPX2 using :ref:`uv`:

.. code-block:: console

   $ uv add httpx2
